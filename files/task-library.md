# ЧАСТЬ 1 — Архитектура трёх слотов

Экран дня всегда выглядит одинаково. Три блока, ни одного лишнего.

```
┌──────────────────────────────────────┐
│  ЯДРО                    день 23/60  │
│  Если 22:30 — телефон на зарядку     │
│  на кухню                            │
│                          [ Сделал ]  │
├──────────────────────────────────────┤
│  ПОДДЕРЖКА                           │
│  ○ Свет в первый час                 │
│  ○ Кофеин до 15:00                   │
├──────────────────────────────────────┤
│  СЕГОДНЯ                             │
│  Пройти одну остановку пешком        │
│                          [ Сделал ]  │
│                    [ Своя задача → ] │
└──────────────────────────────────────┘
```

### Слот 1 — Ядро

**Одна активная задача. Живёт 60 дней минимум. Не ротируется.**

Это единственное место, где формируется привычка. Всё остальное — обвязка.

- Берётся из лестницы категории-слабого-звена.
- Меняется только при переходе на следующий тир (условия ниже) или при явном запросе пользователя.
- Если адгезия за 14 дней ниже 40% — предлагаем **спуститься на тир ниже**, а не давить. Формулировка: «Эта не приживается. Возьмём проще?»

### Слот 2 — Поддержка

Задачи, прошедшие ядро. Отметка в одно касание, без карточки и без пояснений.

- Попадает сюда автоматически при переходе на следующий тир.
- Максимум 5 видимых. Дальше самые старые сворачиваются в счётчик «+3 автоматических».
- **Не отмеченная поддержка не наказывает.** Она влияет на Состояние мягко (см. часть 2), но не ломает ядро и не тратит прощённые дни.

### Слот 3 — Сегодня

Одна короткая задача, каждый день новая. Даёт новизну и XP, не мешая ядру.

Две ветки:
- **Из библиотеки** — ротация по правилам (часть 4).
- **Своя** — пользователь ставит сам (часть 5).

# ЧАСТЬ 2 — Два числа

| | **Состояние** | **Уровень** |
|---|---|---|
| Что показывает | как человек живёт | сколько прошёл |
| Единица | 0–100 по каждой из 6 категорий | XP, без потолка |
| Источник | зафиксированное поведение | выполненные задачи |
| Может падать | да | **никогда** |
| Где видно | гексаграмма, главный экран | полоска, профиль |

## Как меняется Состояние

Ключевое правило: **скор реагирует на поведение, а не на нажатие кнопки.**

```
Отметка «сделал»      → +сдвиг категории вверх
Отметка «не сделал»   → −сдвиг категории вниз
Нет отметки вообще    → дрейф к базовой линии, медленно
```

Третья строка — самая важная. Забыл отметить ≠ сделал плохо. У нас в анкете «просто забываю» стоит отдельным стоп-фактором; наказывать за это тем же механизмом, что за реальный срыв, — противоречие.

**Формула сдвига за день:**

```
Δ = base × weight × decay

base:    ядро ±2.0 | поддержка ±0.8 | микрозадача ±0.4
weight:  вес категории задачи = 1.0, смежной = 0.3
decay:   при отсутствии отметки Δ = −0.25 в сторону базовой линии

Состояние_new = clamp(0, 100, Состояние_old + ΣΔ)
```

Смежные категории (weight 0.3): сон↔энергия, движение↔энергия, ум↔сон, еда↔энергия. Это отражает реальные связи и делает картину живой — человек работает над сном, а подрастает и энергия.

**Пересчёт по окну.** Раз в 14 дней Состояние пересобирается по фактическим логам за период, а не накапливается бесконечно. Это не даёт числу уплыть от реальности.

## Как меняется Уровень

```
Ядро выполнено          +10 XP
Поддержка отмечена      +3 XP каждая
Микрозадача выполнена   +5 XP
Своя задача выполнена   +5 XP
Неделя без пропусков    +25 XP бонус
Переход на новый тир    +100 XP
```

XP не отнимается никогда. Ни за пропуск, ни за срыв, ни за паузу в приложении на месяц.

## Разблокировка тиров

**Не по XP.** XP фармится лёгкими микрозадачами в других категориях — если гейтить им, человек откроет тир 4 по сну, ни разу нормально не поспав.

```
Тир N+1 в категории открывается, когда:
  адгезия задачи тира N ≥ 70% за последние 14 дней
  И прошло ≥ 21 день с момента получения задачи

адгезия = выполнено / (дней активно − прощённые дни)
```

Отдельно по каждой категории. Профиль «Сон тир 3 / Движение тир 1» — нормальная картина, а не баг.

## Прощённые дни

2 на каждые 30, скользящее окно. Показываются как ресурс, не как поблажка:

> Прощённые дни: 2 из 2

При пропуске списывается автоматически, без вопроса. Уведомление на следующий день:

> Вчера пропустили — использовали прощённый день. Осталось 1 из 2.
> Цепочка цела. Так и должно работать: в исследовании, на котором это построено, пропуск одного дня не влиял на формирование привычки.

Когда оба потрачены и случается третий пропуск — **цепочка всё равно не сгорает**. Меняется только формулировка:

> Три пропуска за две недели. Это не провал — это сигнал, что задача не подошла. Возьмём проще?

Кнопки: `Оставить как есть` / `Спуститься на тир ниже`

# ЧАСТЬ 3 — Шесть лестниц

Правила чтения:

- Каждый тир **включает все предыдущие** (они уходят в Поддержку).
- Формат задачи всегда `если [якорь] → [действие]` (Gollwitzer & Sheeran, 2006).
- `Якорь` — существующее событие дня, а не время на часах, где это возможно.
- `Источник` — то, что покажется по тапу на иконку «i».
- Прохождение всех пяти тиров категории ≈ **10–12 месяцев**.

## 🌙 СОН

Базовая категория. Если Сон и что-то ещё одинаково провалены — начинаем со Сна: он тянет за собой энергию и ум.

### Тир 1 — Граница

> **Если время 22:30 — телефон едет на зарядку на кухню**

*Не «ложись раньше». Просто убери из спальни то, из-за чего не ложишься.*

**Якорь:** будильник 22:30
**Источник:** Van Dongen et al., *Sleep*, 2003 — `10.1093/sleep/26.2.117`
**Пояснение:** 14 дней по 6 часов дают накопленное падение внимания, которое сам человек почти не замечает. Начинаем с того, что отодвигает отбой.

### Тир 2 — Подъём

> **Если сработал будильник — встаю, не переставляю**

*Фиксированный подъём держит ритм сильнее, чем фиксированный отбой. Ложиться вовремя станет проще само.*

**Якорь:** будильник
**Источник:** Van Dongen et al., 2003
**Настройка:** время подъёма берётся из анкеты, допуск ±30 мин

### Тир 3 — Кофеин

> **Если время после 15:00 — кофе меняю на воду**

*Кофеин за 6 часов до сна сокращает сон примерно на час. Участники исследования этого не замечали — по дневникам они спали нормально, приборы показывали другое.*

**Якорь:** 15:00 / желание выпить кофе
**Источник:** Drake et al., *J Clin Sleep Med*, 2013 — `10.5664/jcsm.3170`
**Оговорка в карточке:** доза в исследовании — 400 мг, это около четырёх чашек

### Тир 4 — Свет

> **Если проснулся — 10 минут у окна или на улице, до телефона**

*Утренний свет — самый сильный сигнал для внутренних часов.*

**Якорь:** пробуждение
**Источник:** Wright et al., *Current Biology*, 2013 — `10.1016/j.cub.2013.06.039`
**Оговорка:** в исследовании неделя при одном естественном свете сдвинула часы на 2 часа раньше; n=8, кемпинг. Не обещаем два часа.

### Тир 5 — Окно

> **Если 22:15 — начинаю укладываться, семь дней в неделю**

*Выходные ломают ритм сильнее, чем один поздний вторник.*

**Якорь:** 22:15
**Источник:** Van Dongen et al., 2003
**Допуск:** ±20 мин

## ⚡ ЭНЕРГИЯ

Категория-производная. Если Энергия провалена вместе со Сном — работаем со Сном, Энергия подтянется через смежный вес.

### Тир 1 — Свет

> **Если проснулся — сначала к окну, потом всё остальное**

*Самый дешёвый способ сдвинуть день. Ничего не нужно, кроме окна.*

**Якорь:** пробуждение
**Источник:** Wright et al., 2013

### Тир 2 — Первый час

> **Если проснулся — первые 15 минут без телефона**

*Не про цифровой детокс. Про то, чтобы первые решения дня были ваши, а не ленты.*

**Якорь:** пробуждение
**Источник:** — (поведенческая задача, без исследования; см. правило честности в части 6)

### Тир 3 — Разрыв сидения

> **Если прошёл час сидя — встаю на 2 минуты**

*ВОЗ отдельно рекомендует сокращать время сидения, независимо от того, тренируетесь вы или нет.*

**Якорь:** таймер 60 мин в рабочие часы
**Источник:** Bull et al. / ВОЗ, *BJSM*, 2020 — `10.1136/bjsports-2020-102955`

### Тир 4 — Провал дня

> **Если после обеда тянет в сон — 10 минут пешком вместо кофе**

*Кофе в это время заберёт час сна вечером. Ходьба — нет.*

**Якорь:** послеобеденный спад (13:00–16:00)
**Источник:** Drake et al., 2013 + Bull et al., 2020

### Тир 5 — Стабильность

> **Если закончил работу — фиксирую время и не возвращаюсь**

*Размытая граница дня съедает вечер, вечер съедает сон, сон съедает следующий день.*

**Якорь:** закрытие ноутбука
**Источник:** Van Dongen et al., 2003

## 🏃 ДВИЖЕНИЕ

Самая безопасная категория с точки зрения источников — стоит на официальных рекомендациях ВОЗ.

### Тир 1 — Попутно

> **Если говорю по телефону — иду пешком**

*Не тренировка. В зачёт по рекомендациям ВОЗ идут куски любой длины.*

**Якорь:** входящий/исходящий звонок
**Источник:** Bull et al. / ВОЗ, 2020 — `10.1136/bjsports-2020-102955`
**Пояснение:** в рекомендациях 2020 года отдельно оговорено, что эпизоды любой продолжительности засчитываются — в отличие от версии 2010 года

### Тир 2 — Каждый час

> **Если встал за водой — прохожу лишний круг**

*Цель — не шаги, а меньше непрерывного сидения.*

**Якорь:** любой подъём со стула
**Источник:** Bull et al., 2020

### Тир 3 — Двадцать минут

> **Если вторник или четверг — 20 минут непрерывной ходьбы**

*Первый повторяющийся блок. Два раза в неделю, фиксированные дни.*

**Якорь:** день недели + время из анкеты
**Источник:** Bull et al., 2020

### Тир 4 — Норма

> **Набираю 150 минут в неделю, любыми кусками**

*Нижняя граница рекомендации ВОЗ для взрослых. Верхняя — 300.*

**Якорь:** недельный счётчик
**Источник:** Bull et al., 2020
**Отображение:** прогресс-полоса недели, а не ежедневная галочка

### Тир 5 — Оптимум

> **45 минут, 3–5 раз в неделю. Больше — не лучше**

*По крупнейшему исследованию связи движения и состояния (1.2 млн человек) максимум пользы для настроения — именно здесь. Больше 23 сессий в месяц или дольше 90 минут связано с худшими показателями.*

**Якорь:** расписание недели
**Источник:** Chekroud et al., *Lancet Psychiatry*, 2018 — `10.1016/S2215-0366(18)30227-X`
**Оговорка обязательна:** поперечное исследование, показывает связь, а не причину

> ⭐ **Тир 5 — единственная задача в приложении, которая ставит потолок, а не пол.** Это точка отстройки: весь жанр продаёт «больше и жёстче», у нас есть крупнейшее исследование, говорящее об оптимуме посередине.

## 🍽 ЕДА

**Жёсткое ограничение категории:** ни одна задача не содержит цифр по калориям, весу, размеру порции или списков запрещённых продуктов. Только контекст приёма пищи и добавление, никогда ограничение.

Причина: Jacka измеряла эффект от **улучшения качества** рациона, а не от ограничения. Плюс задачи-ограничители в трекере с ежедневной отметкой — прямой путь к нездоровым паттернам у части аудитории.

### Тир 1 — Без экрана

> **Если сел есть — телефон экраном вниз**

*Один приём пищи в день с вниманием на еде.*

**Якорь:** начало приёма пищи
**Источник:** Jacka et al., *BMC Medicine*, 2017 — `10.1186/s12916-017-0791-y`

### Тир 2 — Сидя

> **Если ем — сижу за столом, а не на ходу**

*Еда стоя у холодильника не считается приёмом пищи ни для головы, ни для желудка.*

**Якорь:** начало приёма пищи
**Источник:** Jacka et al., 2017

### Тир 3 — Утро

> **Если прошёл час после подъёма — завтракаю**

*Не про «завтрак обязателен». Про то, чтобы первый приём пищи не сползал на три часа дня.*

**Якорь:** +60 мин от пробуждения
**Источник:** Jacka et al., 2017
**Условие показа:** только если в анкете первый приём пищи позже 12:00

### Тир 4 — Добавить

> **Если готовлю ужин — добавляю одну овощную позицию**

*Добавляем, а не убираем. В исследовании работала именно замена состава, а не сокращение.*

**Якорь:** приготовление ужина
**Источник:** Jacka et al., 2017

### Тир 5 — План

> **Если утро — решаю, что буду есть сегодня**

*Решение, принятое утром на трезвую голову, лучше решения в 20:00 на голодный желудок.*

**Якорь:** утро
**Источник:** Gollwitzer & Sheeran, 2006 — `10.1016/S0065-2601(06)38002-1`

## 🧠 УМ

Самая нагруженная доказательствами категория после Движения.

### Тир 1 — Дыхание

> **Если чувствую, что разгоняюсь — 5 минут дыхания с длинным выдохом**

*Вдох через нос, короткий добор, длинный выдох через рот. Пять минут.*

**Якорь:** ощущение напряжения / фиксированное время
**Источник:** Balban et al., *Cell Reports Medicine*, 2023 — `10.1016/j.xcrm.2022.100895`
**Пояснение:** в рандомизированном исследовании пять минут такого дыхания в день улучшали настроение сильнее, чем те же пять минут медитации осознанности

> ⭐ **Лучшая первая задача во всём приложении.** Пять минут, ничего не нужно, эффект ощущается в первый день. Если слабое звено — Ум, начинаем отсюда. Если человек в анкете указал бюджет 5 минут — тоже отсюда, независимо от категории.

### Тир 2 — Первые минуты

> **Если проснулся — 15 минут без ленты**

**Якорь:** пробуждение
**Источник:** — (поведенческая)

### Тир 3 — Практика внимания

> **Если закрыл ноутбук — 10 минут тишины**

*Метаанализ рандомизированных испытаний даёт небольшое-умеренное снижение тревожности и стресса. Небольшое-умеренное — так и написано в исследовании, мы не преувеличиваем.*

**Якорь:** закрытие ноутбука
**Источник:** Goyal et al., *JAMA Internal Medicine*, 2014 — `10.1001/jamainternmed.2013.13018`

### Тир 4 — Выгрузка

> **Если 21:00 — выписываю всё, что крутится в голове**

*Для тех, кто не может «выключить» голову перед сном.*

**Якорь:** 21:00
**Источник:** Gollwitzer & Sheeran, 2006 (перевод незакрытых намерений в план)
**Условие показа:** приоритет для ответивших «почти каждый вечер» на в.13

### Тир 5 — Граница дня

> **Если закончил работу — три минуты на план завтра, потом закрываю**

**Якорь:** конец рабочего дня
**Источник:** Gollwitzer & Sheeran, 2006

# ЧАСТЬ 4 — Микрозадача дня

Короткая, разовая, не требует подготовки. Выполняется за 1–10 минут.

## Правила ротации

```
1. Не из категории текущего ядра — чтобы не конкурировать за внимание
2. Не повторяется чаще раза в 90 дней
3. Учитывает бюджет времени из в.16
4. Пн–Пт: короткие (1–5 мин). Сб–Вс: можно до 15 мин
5. Если 3 микрозадачи подряд пропущены — переключаемся на самые лёгкие
```

Ниже по 7 штук на категорию — это стартовый набор. Целевой объём — **150–200**, набирается по шаблонам в конце раздела.

## Шаблоны для расширения до 200

Копирайтеру: каждая микрозадача строится по одной из шести схем.

| Схема | Пример |
|---|---|
| **Замени** одно на другое | кофе → вода, лифт → лестница, доставка → готовка |
| **Убери** один объект | лампа из спальни, приложение с экрана, телефон со стола |
| **Добавь** одну единицу | овощ, стакан, остановка пешком, 5 минут |
| **Заметь** и зафиксируй | во сколько устал, сколько кофеина, когда был спад |
| **Сдвинь** на 15 минут | отбой, подъём, обед, последний кофе |
| **Сделай раньше** обычного | ужин, отбой, зарядка телефона |

Шесть схем × шесть категорий × 5–6 вариаций = **180–216 задач**. Это 3–4 дня работы копирайтера, не месяц.

# ЧАСТЬ 5 — Пользовательская задача

Пользователь ставит себе микрозадачу сам. Кнопка `Своя задача →` в слоте 3.

## Форма ввода

```
┌────────────────────────────────────────┐
│  Своя задача на сегодня                │
│                                        │
│  Если  [ вернусь домой          ]      │
│  то    [ 15 минут разберу стол  ]      │
│                                        │
│  Категория:  🌙 ⚡ 🏃 🍽 💧 🧠          │
│                                        │
│              [ Поставить ]             │
└────────────────────────────────────────┘
```

**Два поля, не одно.** Это принципиально: форма заставляет сформулировать задачу как if-then, то есть в формате с измеренным эффектом d = 0.65. Мы не объясняем это пользователю — мы просто не даём поля для «буду больше двигаться».

Подсказка под полями:
> Привяжите к тому, что и так случится сегодня. Планы вида «если — то» выполняются заметно чаще.

## Ограничения ввода

```
Поле «если»:  максимум 40 символов
Поле «то»:    максимум 60 символов
Категория:    обязательна (нужна для начисления в Состояние)
Частота:      одна своя задача в день
XP:           +5, столько же, сколько за библиотечную
```

## Фильтр безопасности ⭐

Пользовательский ввод в трекере с ежедневной отметкой — это место, где человек может закрепить вредный паттерн, а приложение будет его подкреплять галочкой и очками. Это надо закрыть до релиза, а не после.

**Реализация на MVP: список стоп-слов на клиенте, без ИИ.** Срабатывает — показываем мягкий отказ, не блокируем экран.

Категории стоп-слов:

| Группа | Примеры триггеров |
|---|---|
| Ограничение питания | «не есть», «голодать», «пропустить приём», «до N ккал», «сбросить N кг», «ничего не ем» |
| Самонаказание | «наказать себя», «заслужил», «если не сделаю, то не буду есть/спать» |
| Экстремальный режим | «не спать», «без сна», «сутки без», «только вода» |
| Самоповреждение | соответствующая лексика |

**Текст отказа — без нотаций:**

> Такую задачу мы не поставим.
>
> Приложение отмечает выполнение галочкой каждый день — а это плохой механизм для целей, связанных с ограничением еды или сна. Он закрепляет то, что закреплять не стоит.
>
> Если хотите работать с питанием — в категории «Еда» есть задачи, которые добавляют, а не убирают.

Кнопки: `Понятно` / `Изменить задачу`

**Дополнительно:** при срабатывании фильтра из группы «самоповреждение» — не отказ, а экран с контактами поддержки. Это отдельная ветка, не смешивать с обычным отказом.

**Отдельно:** если пользователь трижды за неделю пытается поставить задачу из группы «ограничение питания», категория «Еда» у него переводится в мягкий режим — задачи тира 3+ не выдаются, микрозадачи по еде из ротации убираются. Молча, без уведомления.

## Влияние на Состояние

Своя задача начисляет в выбранную категорию по тому же весу, что микрозадача из библиотеки (`base = ±0.4`). Никаких коэффициентов «своё дешевле» — это демотивирует ровно тех, кто наиболее вовлечён.

# ЧАСТЬ 6 — Правила копирайтинга

## Формула задачи

```
Если [якорь] — [действие]
```

- **Якорь** — событие, которое случится сегодня в любом случае. «Если проснулся», «если сел есть», «если закончил работу». Время на часах — только когда события нет («если 22:30»).
- **Действие** — глагол первого лица настоящего времени. «Иду», «убираю», «ставлю». Не «нужно», не «постарайтесь», не инфинитив.
- **Длина** — до 60 символов. Не влезает — задача слишком сложная для этого тира.

## Подзаголовок

Одно предложение, курсивом, под задачей. Функция — снять сопротивление, а не мотивировать.

Хорошо:
> *Не тренировка. Не абонемент. Просто не сидеть, когда можно не сидеть.*

Плохо:
> *Каждый шаг приближает вас к лучшей версии себя!*

## Правило честности источника

У задачи либо есть исследование, либо честно нет.

```
Есть источник  → иконка «i», по тапу: пересказ + журнал + год + DOI
Нет источника  → иконки нет. Ничего не выдумываем.
```

В библиотеке выше без источника идут: Энергия Т2, Ум Т2, вся категория Вода, большинство микрозадач. **Это нормально и это не надо прятать.** Приложение, где у 60% задач есть ссылка, а у 40% честно нет, вызывает больше доверия, чем приложение, где ссылка есть у всех — потому что во втором случае половина ссылок натянута, и это видно.

## Стоп-лист формулировок

| Нельзя | Почему |
|---|---|
| «Ты должен», «обязательно» | приказ вместо плана |
| «Всего 5 минут!» | обесценивание усилия |
| «Лучшая версия себя» | пустая формула жанра |
| Восклицательные знаки | у нас спокойный тон |
| «Не забудь» | предполагает вину |
| Цифры калорий, веса, размера порции | см. ограничение категории «Еда» |
| «Доказано, что…» | наука не доказывает окончательно |

# ЧАСТЬ 7 — Схема данных

Минимальный набор для MVP.

```
task_template
  id
  category          sleep|energy|movement|food|water|mind
  slot              core|micro
  tier              1..5 (null для micro)
  anchor_text       "22:30"
  action_text       "телефон на зарядку на кухню"
  subtitle
  source_doi        nullable ← null это валидное значение
  source_citation   nullable
  source_note       nullable (оговорки: n=8, поперечное и т.д.)
  min_budget_min    5|15|30 (из в.16)
  stopfactor_tags   [] (из в.17)

user_task
  id, user_id, template_id
  slot              core|support|micro|custom
  custom_anchor     nullable
  custom_action     nullable
  category
  started_at
  status            active|graduated|dropped

task_log
  user_task_id
  date
  status            done|skipped|no_entry
  xp_awarded

user_state
  user_id
  sleep, energy, movement, food, water, mind   0..100
  baseline_*                                    из анкеты, не меняется
  recalculated_at
  level_xp
  grace_days_left
  grace_window_start

user_flags
  food_soft_mode    bool  ← из фильтра безопасности
  budget_minutes
  stopfactor_type   category|system
  stopfactor_value
```

**Про `source_doi = null`.** Это не заглушка и не долг. Это осознанное значение, означающее «у задачи нет исследования, и мы это показываем». В интерфейсе — просто отсутствие иконки «i».
