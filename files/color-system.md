# ЧАСТЬ 1 — Почему настоящий чёрный

`#000000`, не «почти чёрный».

- **OLED:** пиксели физически выключены. Бесконечный контраст и заметная экономия батареи на приложении, которое открывают утром и вечером.
- **Карточки читаются как объекты в пустоте**, а не как блоки на сером фоне. Это даёт глубину без единой тени.
- **Насыщенный акцент перестаёт кричать.** Главная ошибка первой концепции была в попытке приглушить всё разом — получилась каша без точек притяжения. На настоящем чёрном яркий синий выглядит уместно: фон гасит его сам.

# ЧАСТЬ 2 — Четыре приёма

Электрик — холодный цвет. Без сознательной коррекции интерфейс уходит в казённый, «военный» тон. Четыре приёма, которые это снимают, не выходя за пределы выбранной пары.

### 1. Поверхности с синим подмесом

Не нейтральный серый, а серый с тем же синим внутри: `#0E0F14`, `#161822`, `#1F2230`. Карточки перестают выглядеть чужеродными плитками и читаются как часть одной среды.

Нейтральный серый рядом с синим акцентом всегда даёт казённость — это самая частая причина «военного» ощущения в тёмных интерфейсах, и её почти никогда не замечают напрямую.

### 2. Акцент — семейство, а не один тон

Четыре ступени вместо одного синего: насыщенный для кнопок, светлый для текста и меток, глубокий для заливок, тусклый для фонов состояний. Один-единственный синий на весь интерфейс и есть скука.

### 3. Тёплый противовес

Янтарь `#FFB86B` ровно в трёх местах: чип прощённых дней, замыкание кольца на 60-й день, празднование дня 1.

Он работает именно потому, что редкий. Одна тёплая нота на холодном экране считывается как человечность; раскрасить им половину интерфейса — превратить в шум.

### 4. Текст почти тёплый

`#F2F1EF` вместо холодного `#EDEFF5`. Разница в пару процентов, но рядом с синим она заметно смягчает картинку. Чистый `#FFFFFF` не использовать нигде — даёт гало на чёрном.

# ЧАСТЬ 3 — Поверхности

| Токен | Hex | Где |
|---|---|---|
| `canvas` | `#000000` | фон всех экранов |
| `surface1` | `#0E0F14` | карточки |
| `surface2` | `#161822` | вложенные блоки, поля ввода |
| `surface3` | `#1F2230` | выбранное состояние, чипы |
| `border` | `#2A2E3C` | обводки 0.5 px, разделители |

Теней нет. Иерархия — ступень поверхности, обводка `0.5px`, расстояние.

# ЧАСТЬ 4 — Акцент

| Токен | Hex | Где |
|---|---|---|
| `accent` | `#4361FF` | кнопка действия, активный прогресс |
| `accentBright` | `#7C8FFF` | акцентный текст, метки, ссылки |
| `accentDeep` | `#2A3AA8` | заливки под текстом, нажатое состояние |
| `accentDim` | `#141B3D` | фон активных состояний, выбранный вариант ответа |
| `onAccent` | `#F0F2FF` | текст на акцентной кнопке |

**Правило `accentBright`.** Насыщенный `#4361FF` на чёрном не проходит по контрасту для мелкого текста. Для любого текста меньше 18 px использовать только `#7C8FFF`. `#4361FF` — цвет заливок, не букв.

# ЧАСТЬ 5 — Текст

| Токен | Hex | Где |
|---|---|---|
| `textPrimary` | `#F2F1EF` | заголовки, текст задачи |
| `textSecondary` | `#9096A8` | подзаголовки, пояснения |
| `textMuted` | `#656B7C` | метки, счётчики, служебное |

`textMuted` на `canvas` даёт около 4.6:1 — достаточно для служебного текста от 11 px. На `surface2` контраст падает; там метки набираются `textSecondary`.

# ЧАСТЬ 6 — Тёплый противовес

| Токен | Hex | Где |
|---|---|---|
| `warm` | `#FFB86B` | чип прощённых дней, замыкание кольца, день 1 |
| `warmDim` | `#3A2617` | фон этого чипа |

**Также заменяет собой красный** во всех сценариях: предупреждения, предложение спуститься на тир, экран срыва. Красного в системе нет вообще — решение принято в `design-concept.md`, часть 1, и здесь оно не меняется.

**Список мест исчерпывающий.** Если тёплый цвет появляется где-то ещё — это ошибка, а не решение дизайнера.

# ЧАСТЬ 7 — Шесть категорий

| Категория | Hex | Тон |
|---|---|---|
| Сон | `#8B7BFF` | фиолетовый |
| Энергия | `#FFB020` | янтарный |
| Движение | `#3DDC97` | мятный |
| Еда | `#F4704E` | коралловый |
| Вода | `#22D3EE` | циан |
| Ум | `#DE7BD4` | розово-лиловый |

**Категории обходят синюю зону.** Синий отдан действию, поэтому ни один категорийный цвет не попадает в диапазон 220–240° — иначе кольцо начнёт спорить с кнопкой.

**Самая тесная пара — Энергия и Еда.** Янтарь и коралл близки по тону, и на маленьком кольце их можно спутать. Здесь особенно важно правило дублирования: у каждой категории всегда есть иконка и подпись, цвет никогда не единственный носитель смысла.

**Тёплый `#FFB86B` и Энергия `#FFB020` намеренно разведены** по светлоте и насыщенности. Не свести их в один токен: у них разные роли, и объединение сломает смысл чипа прощённых дней.

# ЧАСТЬ 8 — Свечение и градиенты

Синий на чёрном светится лучше любого другого цвета. Это главное преимущество выбранной пары, и им нужно пользоваться — но точечно.

### Где свечение есть

| Место | Как |
|---|---|
| Заставка | радиальный градиент от центра, `rgba(67,97,255,0.35)` |
| Кольцо состояния | мягкое свечение под дугами, radius 40 px |
| Карточка ядра | радиальный градиент из левого верхнего угла, до 30% |
| Экран итога дня 14 | свечение под кольцом |
| Замыкание на 60-й день | вспышка `warm`, один раз |

### Где свечения нет

Списки, настройки, экран вопросов, экран источников, поддержка, история. Везде, где человек читает или сканирует.

**Причина.** Свечение на каждом экране через неделю начинает мешать читать и раздражать. Точечное — воспринимается как качество исполнения. Это ровно та точка притяжения, которой не хватало первой концепции, но она работает только пока редкая.

### Правило градиента

Один градиент = один цвет с разной прозрачностью. Двухцветных переходов нет — они и есть визуальный код жанра «lock in», от которого мы отстраиваемся.

# ЧАСТЬ 9 — Токены

```json
{
  "color": {
    "canvas":        "#000000",
    "surface1":      "#0E0F14",
    "surface2":      "#161822",
    "surface3":      "#1F2230",
    "border":        "#2A2E3C",

    "accent":        "#4361FF",
    "accentBright":  "#7C8FFF",
    "accentDeep":    "#2A3AA8",
    "accentDim":     "#141B3D",
    "onAccent":      "#F0F2FF",

    "textPrimary":   "#F2F1EF",
    "textSecondary": "#9096A8",
    "textMuted":     "#656B7C",

    "warm":          "#FFB86B",
    "warmDim":       "#3A2617",

    "neutralDown":   "#7C8296",

    "catSleep":      "#8B7BFF",
    "catEnergy":     "#FFB020",
    "catMovement":   "#3DDC97",
    "catFood":       "#F4704E",
    "catWater":      "#22D3EE",
    "catMind":       "#DE7BD4"
  },
  "glow": {
    "accent": "rgba(67, 97, 255, 0.35)",
    "warm":   "rgba(255, 184, 107, 0.30)"
  }
}
```

`neutralDown` — стрелка вниз на экране пересчёта. Не красный, не синий: нейтральный, чтобы падение категории читалось как факт, а не как приговор.

# ЧАСТЬ 10 — Проверки

Перед сдачей макетов прогнать:

1. **Контраст.** `textSecondary` на `surface1` — не менее 4.5:1. `accent` не используется для текста мельче 18 px.
2. **Красный.** Поиск по макетам: красного нет ни в одном состоянии, включая ошибки и срыв.
3. **Тёплый.** Встречается ровно в трёх местах из части 6. Больше — ошибка.
4. **Свечение.** Нет ни на одном экране со списками и чтением.
5. **Категории.** Каждая сопровождена иконкой и подписью; цвет нигде не единственный носитель смысла.
6. **320 px.** Кольцо с подписями снаружи не помещается — нужен компактный режим.
7. **Светлая тема.** В первой версии не делается. Токены названы по роли, поэтому добавляется позже без переписывания компонентов.
